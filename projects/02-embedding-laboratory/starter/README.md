# Project 02: The Embedding Laboratory

The project is contained in `embedding_lab.ipynb`. Students explore pretrained
GloVe, train Skip-gram Word2Vec with PyTorch, and complete three guided pieces
of a GloVe implementation.

## Local setup

```bash
uv sync
uv run jupyter lab embedding_lab.ipynb
```

The notebook may also be uploaded directly to Google Colab. The first run
downloads `glove-wiki-gigaword-50` and `text8`; later runs use the Gensim cache.
